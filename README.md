# Mouthy

Mouthy is a free, open-source, offline-first desktop text-to-speech app for macOS. Highlight text in any app, press a global hotkey, and hear it read aloud by a local neural voice; press the hotkey again to stop.

**Status:** early development, not yet usable. See [PLAN.md](PLAN.md) for the roadmap and current progress.
