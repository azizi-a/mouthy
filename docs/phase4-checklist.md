# Phase 4 checklist (0.6.0: Linux on Wayland, seven languages)

Two parts: the Bazzite laptop with the new AppImage, then a short regression run on the Mac. The laptop part covers only what the earlier smoke runs did not prove on this build. Tick each step and say its number with pass or fail.

**Before you start (laptop)**

- Get `Mouthy_0.6.0_amd64.AppImage` from the draft release into `~/Downloads`.
- espeak-ng and wl-clipboard already come with Bazzite. If a step says one is missing, install it with `brew install espeak-ng` or `brew install wl-clipboard`, then quit and start Mouthy again.
- Make the test texts once (paste the whole block into Konsole; do the same on the Mac for part b):

```bash
mkdir -p ~/mouthy-test && cd ~/mouthy-test
printf 'Hola. Mañana a las tres y media vamos al mercado con mi hermana, y después volvemos a casa.\n' > es.txt
printf 'Bonjour. Demain à quinze heures, nous irons au marché avec ma sœur, puis nous rentrerons à la maison.\n' > fr.txt
printf '你好。今天天气很好，我们下午三点去公园散步。\n' > zh.txt
printf '今日は天気がいいので、二、三日したら友達と公園まで歩きます。\n' > ja.txt
printf 'See the Full Changelog for the details. The getUserName function reads tsconfig first.\n' > en.txt
printf 'Mouthy should read this whole paragraph aloud. The imple-\nmentation joins a word that was broken at the end of a line, and a well-\nknown phrase keeps its two words. It must keep reading after each break\nuntil the very last word, which is end.\n' > hyphen.txt
```
