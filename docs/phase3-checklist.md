# Phase 3 checklist (0.4.0: voice picker, blends, clipboard hotkey, icon)

Run on the 0.4.0 dmg from the draft release, not `tauri dev`: under dev, Accessibility is charged to the terminal. Nobody has clicked or listened to these features in the built app yet, so this is their only end-to-end check.

**Before you start**

- Keep your 0.3.0 data: the int8 model and `af_alloy` should already be in Settings → Models. Steps 16–27 download `bm_lewis`, `bm_george`, `jf_alpha` and the fp32 model, so Wi-Fi stays on.
- System Settings → Accessibility → Spoken Content → Speak selection is off (it also uses ⌥⎋).
- For step 28, start Kokoro-FastAPI yourself (`curl http://127.0.0.1:8880/v1/audio/voices` answers).

**What to report back**

- Pass or fail for each step. For a failure, the step number and the last lines of `~/Library/Logs/com.azizi.mouthy/mouthy.log` (times are UTC).
- Whether the 70/30 Lewis/George blend in step 19 sounds like a mix, and how `jf_alpha` sounds reading English.
- Whether the menu-bar icon reads well at that size on light and dark (steps 4–5), or needs a simpler shape.
- Whether ⌥⇧⎋ clashes with anything you use.
