# Phase 2 definition-of-done checklist (offline voice)

Run on the built app (`bun run tauri build --bundles app`), not `tauri dev`: under dev, Accessibility is charged to the terminal.

**Before you start**

- Quit any running Mouthy. To start as a fresh install, move its data aside (settings and any downloaded voice files): `mv ~/Library/Application\ Support/com.azizi.mouthy ~/mouthy-data-backup`. An existing settings file from a Phase 1 build keeps the HTTP server, so this matters.
- If an older build was granted Accessibility: `tccutil reset Accessibility com.azizi.mouthy`.
- No speech server is running: `curl -m 3 http://127.0.0.1:8880/v1/audio/voices` must fail. Stop Kokoro-FastAPI if it answers.
- System Settings → Accessibility → Spoken Content → Speak selection is off (it also uses ⌥⎋).
- Put something rich on the clipboard: ⌃⇧⌘4 and drag to copy a screenshot. After every step that speaks, ⌘V into a TextEdit document must paste that image back.

**What to report back**

- Pass or fail for each step. For a failure, the step number and the last lines of `~/Library/Logs/com.azizi.mouthy/mouthy.log` (times are UTC).
- First-audio times: `grep -E 'First audio|Loaded the' ~/Library/Logs/com.azizi.mouthy/mouthy.log | tail -20`.
- The memory figure from step 15, and whether you want Mouthy to unload the voice after some idle minutes (it may not give the memory back to macOS).
- What you heard in step 11: whether it sounds like one sentence, or like several stuck together.
- Re-testing after the P2.7 and P2.8 fixes: steps 4, 11, 15, 17, 20 and 21 are enough.
- Any word Lewis says with an American or otherwise wrong pronunciation (step 4, 12 or your own text), and whether the 62 MB app size is acceptable.

Your old data is in `~/mouthy-data-backup`; to go back to it, quit Mouthy, delete `~/Library/Application Support/com.azizi.mouthy` and move the backup there.
