# Phase 1 definition-of-done checklist

Run on the built app (`bun run tauri build --bundles app`), not `tauri dev`: under dev, Accessibility is charged to the terminal.

**Before you start**

- Kokoro-FastAPI answers: `curl -m 3 http://127.0.0.1:8880/v1/audio/voices` returns a voice list. If it hangs, restart it.
- System Settings → Accessibility → Spoken Content → Speak selection is off (it also uses ⌥⎋).
- Quit any running Mouthy. If an older build was granted Accessibility: `tccutil reset Accessibility com.azizi.mouthy`.
- Put something rich on the clipboard: ⌃⇧⌘4 and drag to copy a screenshot. After every step, ⌘V into a TextEdit document must paste that image back.

| #   | Do                                                                                                                                                                                                                            | Expected                                                                                                                                                                              |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | `open src-tauri/target/release/bundle/macos/Mouthy.app`, click Grant Permission and enable Mouthy in System Settings → Privacy & Security → Accessibility.                                                                    | Tray icon appears. Onboarding shows "All set!" and Settings opens; General shows ⌥⎋, the Speech group shows `http://127.0.0.1:8880` and `bm_lewis`, with Kokoro's voices in a list.   |

The image pastes back.    |

The image pastes back. (With no selection VS Code copies the current line, so that line is read; that is expected.)                               |

| 7   | Select text, hold ⌥, tap ⎋, keep ⌥ held for 2 s, tap ⎋ again, release ⌥.                                                                                                                                                      | First tap starts speaking (no ⌥⌘C side effect in Safari), second tap stops it. Then restore `http://127.0.0.1:8880`.                                                               | An error overlay reads "Speech failed: …" with Open Settings and ×. One click on Open Settings brings the Settings window to the front; × closes the overlay. The app does not crash. |
| 10  | Settings → General → Overlay Position: Top. Select text, press ⌥⎋, then stop. Set it back to Bottom.                                                                                                                          | The overlay appears centred at the top of the screen, then at the bottom again after the change.                                                                                      |

Record any failure with the step number and the last lines of `~/Library/Logs/com.azizi.mouthy/mouthy.log` (times are UTC).
