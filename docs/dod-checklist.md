# Phase 1 definition-of-done checklist

Run on the built app (`bun run tauri build --bundles app`), not `tauri dev`: under dev, Accessibility is charged to the terminal.

**Before you start**

- Kokoro-FastAPI answers: `curl -m 3 http://127.0.0.1:8880/v1/audio/voices` returns a voice list. If it hangs, restart it.
- System Settings → Accessibility → Spoken Content → Speak selection is off (it also uses ⌥⎋).
- Quit any running Mouthy. If an older build was granted Accessibility: `tccutil reset Accessibility com.azizi.mouthy`.
- Put something rich on the clipboard: ⌃⇧⌘4 and drag to copy a screenshot. After every step, ⌘V into a TextEdit document must paste that image back.
